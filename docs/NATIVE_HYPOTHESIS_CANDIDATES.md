# CH-SIMS v2 原生回归：可证伪假设与匹配对照

本文只提出一个优先验证的问题。它基于作者论文和仓库的只读调研；没有改代码、训练模型或使用 GPU。该想法是已有多任务回归与不确定性融合方法在 CH-SIMS v2 标注上的受控测试，不预先宣称原创或有效。

## 最值得先验证的假设

**假设：** 在 CH-SIMS v2 上，真实的 `label_T`、`label_A`、`label_V` 辅助监督会让各模态分支更准确地估计它们对目标 `label_M` 的逐样本预测不确定性。于是，同一组模态回归分布使用 MoNIG 风格的不确定性融合后，在音频/视觉受控噪声或模态缺失下，应比固定权重融合具有更低的原生回归 MAE、更好的误差排序和预测区间校准。关键效应是“模态标签监督 × 不确定性融合”的交互；在两组都使用相同单模态监督的情况下，动态融合仍须优于固定融合，才能把收益归因于融合机制。

这项假设避开已失败的 intervention-utility 路线：门控不学习遮蔽某窗口带来的反事实损失变化，也不以此作为伪标签；它使用回归分布本身给出的预测不确定性。项目已有评估记录显示，旧五分类模型门控与窗口遮蔽损失变化的 Pearson 相关只有 0.031，旧 utility supervision 没有提高 accuracy，见 [`architecture_reassessment.md`](architecture_reassessment.md)。因此不再用同一效用目标包装成新机制。

## 文献给出的范围边界

- **MoNIG 是最直接的融合先例。** 论文为每个模态、拼接后的 pseudo modality、以及融合结果输出 Normal-Inverse-Gamma 分布；通过 NIG summation 根据模态置信参数融合，并显式给出 aleatoric / epistemic uncertainty。损失包括各分支和融合分布的似然与 evidence regularizer。作者在 CMU-MOSI、CMU-MOSEI 报告原生回归/分类指标，也在合成或其他回归设置中测试噪声；其消融对比 average、AU/EU weighted average 与 MoNIG，并用 uncertainty-error inconsistency rate（UEIR）评估不确定性与误差排序。它已经确立了“动态不确定性融合”这个一般机制，不能把本项目泛称为首次可靠性门控。[NeurIPS 2021 论文](https://papers.neurips.cc/paper_files/paper/2021/file/371bce7dc83817b7893bcdeed13799b5-Paper.pdf)、[作者代码](https://github.com/MaHuanAAA/MoNIG)。
- **AV-MC 确立了 CH-SIMS v2 的真单模态监督先例。** 其多任务晚融合骨干对 `m/t/a/v` 各有标量预测头，并分别用 L1 对应地监督多模态及文本、音频、视觉标签；另加入音频/视觉 mixup 一致性。因而任何“增加 `label_T/A/V` 后提高”的结论，都可能只是增加单模态监督或 mixup 的效果。首轮因子实验应固定并拆开单模态监督和不确定性融合，不要把 AV-MC 的全部改动同时叠加到候选方法。[CH-SIMS v2 论文 §4](https://arxiv.org/abs/2209.02604)、[作者代码](https://github.com/thuiar/ch-sims-v2)。
- **Self-MM 也有逐样本辅助损失权重，但不是置信度融合。** 它从多模态标签和表示生成单模态伪标签，按 `tanh(|y_s-y_m|)` 加权单模态 L1，最终输出仍是多模态 `y_m`。这说明“按模态差异重加权辅助任务”已有先例；它没有给回归预测区间或已校准的样本级不确定性。因此本候选不再引入 Self-MM 式差值权重，否则会多出一条监督机制，使因果归因更难。[AAAI 2021 原论文](https://ojs.aaai.org/index.php/AAAI/article/download/17289/17096)、[作者代码](https://github.com/thuiar/Self-MM)。
- **输入依赖的异方差回归与区间校准已有成熟基础。** Kendall–Gal 使用输入依赖 aleatoric variance；MoNIG 将其扩展成显式分模态的分布融合。Kuleshov 等人的 calibrated regression 工作说明概率回归的不确定性可能失准，并提出在独立校准数据上校准预测分位数/区间。因此“输出方差”本身不等于可靠 confidence；本实验必须评区间覆盖，并且任何后校准只能用预留 validation calibration cohort。[Kendall & Gal](https://arxiv.org/abs/1703.04977)、[Kuleshov et al., ICML 2018](https://proceedings.mlr.press/v80/kuleshov18a.html)。

CH-SIMS v2 才提供有监督的 `label_T/A/V`。CMU-MOSEI 没有对应的这组三套人工单模态 sentiment targets；本假设限定在 CH-SIMS v2，不能把效果直接外推到 MOSEI。MOSEI 可作为后续“无单模态标签、只用共同 y”的独立复核，不应伪造或借入伪单模态标签来声称同一机制已复现。

## 最小因子实验

做一个 `单模态监督 S × 动态融合 G` 的 2×2 因子设计：

| 条件 | `label_T/A/V` 辅助损失 | `label_M` 分支分布融合 | 作用 |
|---|---|---|---|
| S0 / G0 | 关 | 固定等权融合 | 共同任务基线 |
| S1 / G0 | 开 | 固定等权融合 | 只测新增单模态监督 |
| S0 / G1 | 关 | MoNIG 风格的逐样本不确定性融合 | 只测融合机制 |
| S1 / G1 | 开 | MoNIG 风格的逐样本不确定性融合 | 联合方法与交互项 |

四个条件使用同一冻结编码器/特征缓存、相同输入序列与 mask、相同 split、模态专家和参数量、相同优化器及步数、相同初始化种子和增强预算。分布头始终存在，`G0` 也保留所有分布输出，只把逐样本融合操作替换成固定等权；需要更强的静态参照时，再加入用固定 validation 搜索预算拟合的全局权重。这样 `S1/G1` 对 `S1/G0` 才是单模态监督条件完全相同时的机制对照；`S1/G0` 对 `S0/G0` 则估计标签监督收益。报告监督主效应、门控主效应和交互项，不只挑最高分的单个组合。

候选结构按可解释、可证伪的方式实现：每个模态分支从同一缓存特征预测共同目标 `label_M` 的标量分布；独立辅助头只在 S1 使用训练 split 中真实对应的 `label_T/A/V`，validation/test 上不计算这些辅助损失，也不把相应标签作为门控或置信度目标。融合用 MoNIG 作者分布算子作为 G1，G0 使用相同分布预测的固定平均。不要把 `label_T/A/V` 的差值直接等同于“模态不可靠”：AV-MC 将单模态与多模态差异作为信息，而非噪声标签；它可能表示有用的非语言情绪线索。不要用 test 标签产生伪目标、调门控权重或校准器。

AV-MC 可作为外部复现对照。若用其 mixup 增强，必须在同一对 G1/G0 比较中完全相同；第一轮建议先不加 mixup，避免“额外单模态标签 + mixup + 不确定性融合”三个因素同时变化。SELF-MM 的伪标签生成和差值加权也留作单独基线，不放进这 2×2 核心实验。

## 压力测试与原生回归置信度

在冻结的同一组 held-out test 特征上预先固定输入变换、随机种子和强度，所有因子条件共用完全相同的变换：

- **干净输入：** 官方 native split 的原始特征，报告官方 CH-SIMS v2 native MAE、Corr、R²、Acc2、Acc2_weak、Acc3、Acc5；回归指标作为主结果，分箱准确率只是分数可读性补充。
- **模态噪声：** 分别对音频、视觉（必要时文本）加预设强度的特征噪声/时间片段遮蔽，另报多模态同时受噪声的情况。噪声以 train 特征统计量归一化、固定随机种子；标签和样本集合保持不变。
- **模态缺失：** 评测 T/A/V 单独缺失及所有非空模态子集。动态融合只在可用模态上重算；固定融合对相同可用集合重归一化。全模态缺失单独报告常数/先验输出，不能算作模型仍有有效证据。

置信度评估使用输出分布而不是把五分类 confidence 改名为回归 confidence：

1. 每个模态分支用 MoNIG 论文的 UEIR 思路，比较预测不确定性与其对 `label_M` 的绝对残差排序；对最终融合输出报告不确定性与实际误差的秩相关/风险覆盖曲线。
2. 从预测分布计算测试 NLL、50/80/90/95% prediction interval 的经验覆盖率和平均区间宽度。MoNIG 输出的分布区间应按其预测分布计算，不要直接把 `1 − confidence` 当误差概率。
3. 如果做后校准，预先保留 validation 的 calibration 子集或使用训练集交叉拟合；只能在这些数据拟合分位数映射/尺度校准，并冻结后一次性报 test。CH-SIMS 标签以 0.2 步长量化，因此 coverage 和区间宽度比只报连续高斯 NLL 更易解释；NLL 仍应附上分布假设。

## 预先规定如何判定

支持假设需要同时看到：

- 在相同 S1 监督下，S1/G1 相对 S1/G0 在预设噪声/缺失条件下降低 MAE，且干净 test 的 MAE 不出现实质退化；
- G1 的分模态 uncertainty-error 排序更好，并且其预测区间在预定名义水平更接近经验覆盖目标，区间宽度没有靠无限变宽来换覆盖；
- 2×2 分析显示单模态监督收益与门控收益可分，最好观察到正交互，而不是把 S1/G0 的提升误报为门控机制收益。

若只有 S1 的单模态监督改善回归而 G1 没超过固定融合，结论应是“额外模态标签有效，可靠性门控未验证”。若预测误差改善但 coverage/UEIR 不改善，不得声称置信度校准成功。若动态权重在实际受噪/缺失的通道上没有相应改变，稳健性提升也不能归功于可靠性估计。

首轮只在 CH-SIMS v2 做三种固定种子，锁定特征、划分、噪声和缺失样本清单；模型选择与置信度校准只用 validation。官方 validation 与 train 存在 source-video 交叠的情况已在项目内记录，最好再报告既有 source-disjoint diagnostic protocol 的敏感性结果，不要把它标作官方 test。

## 证据与待验证部分

已有证据：MoNIG 已证明在若干多模态回归任务（含 MOSEI sentiment）中，可以将模态分布的不确定性用于分布级融合；它也已有平均融合对照、噪声实验和 UEIR。AV-MC 已证明 CH-SIMS v2 有可用的真 `label_T/A/V` 并将其作为 L1 多任务标签。Self-MM 已证明差异加权的单模态辅助任务是已有路线。异方差建模和回归区间校准也有成熟方法基础。

待验证：在 CH-SIMS v2 原生标签、当前固定骨干/特征与当前 split 下，真 T/A/V 辅助监督是否让不确定性更好校准；是否存在 `监督 × 门控` 交互；其增益是否从 clean 输入延伸到噪声和缺失输入。现有论文结果不能回答这些问题，也不能证明本项目候选的准确率、稳健性或新颖性。
