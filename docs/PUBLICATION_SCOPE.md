# Public source and local experiment artifacts

The GitHub repository publishes original Python source, tested CLI entrypoints,
configs, frozen plans, third-party source notices, research reviews, aggregate
results and reproducibility instructions. The package name remains `jevaffect`
to preserve imports and identities of already trained checkpoints.

Media, transcripts, author label tables, feature arrays, downloaded weights,
training checkpoints, backups, work directories and per-sample experimental
records are excluded. No dataset or model redistribution permission is implied
by the repository's MIT code license.

Historical JSON reports are publication copies: long record arrays and
per-sample/response payload fields may be removed. Each changed copy has a
`publication_redaction` section containing the full local report's SHA-256 and
removed JSON paths. Aggregate metrics and audit outcomes remain. Run the
corresponding published audit/analysis script with your legally acquired inputs
to produce a full report locally. References to per-clip records in historical
Markdown describe those full local reports, not the redacted public copy.

Frozen plans, model implementations, training code and registered configs are
copied byte-for-byte. Historical READMEs are retained for their valid commands
and attribution, but their time-specific running/release status is superseded
by the current README, experiment index and publication record.
